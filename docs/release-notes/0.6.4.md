## English

**Preview release** – for testing and feedback. Expect rough edges; presets and parameter IDs stay compatible (append-only). Builds are unsigned.

### Grid keyboard layouts and chord guide
- New layout **Sequential**: one cell right +1, one row up +8 – continuous rows of eight, like reading a page.
- New switch **In Key / Chromatic** for every layout (`harmony.kb.inkey`): In Key plays only the notes of the key, rows count scale steps; Chromatic plays every note with the others dark.
- New switch **Fixed C** (`harmony.kb.fixed`). Off, the new default: the bottom-left cell is the key's root, so a chord shape plays the same chord in every key. On: it is C.
- The old *In Key* layout now opens as **Fourths + In Key**; projects and presets that used it open that way.
- New encoder page **Harmony > Grid** (layout, In Key / Chromatic, Fixed C). **Chord guide** with grip diagrams in the Harmony documentation and the in-app help.

### Grid controller
- **Hold Scales** to show the grid options on its display; the upper buttons choose layout, In Key, Fixed C, root and scale. A tap steps to the next layout. Display line 4 shows layout / In Key / Fixed C / octave.
- **Browse mode**: the preset library on the controller's display – list with neighbours, filters (category, engine, source, favourites, tag, rating, sort) on the encoders, up / down auditions, Select or a part button loads, Shift = favourite. The screen library follows.
- **Many more buttons** mapped and lit by state: Mute / Solo, Volume and Pan & Send pages for the four parts, Device (FX editor), Track (mixer), Clip (tape), Accent, Quantize, Duplicate / Double, Delete + step, New, Fixed Length, Automation, Add Effect, User (breeding), and the timing buttons 1/4 ... 1/32t as note repeat while held.
- **Foot pedal**: a sustain pedal in the controller's pedal jack now holds notes (sustain CC 64, sostenuto CC 66, CC 67 passed on), also in MPE / Fingerboard parts. It was taken as a button press before.
- Display line 3: a long preset name is cut to its column, with a space before the part.

### Arpeggiator and pedals
- The **sustain pedal** (from MIDI, host, the grid controller or an MPE master channel) now holds the arpeggio's notes: released keys stay in the pattern until pedal up, keys pressed meanwhile are added. **Sostenuto** holds only the keys down when it was pressed. Pedal up with no key held stops the arpeggio cleanly.
- With **Latch** on, keys pressed under the pedal add to the latched set.

### FX editor
- The picture follows encoder, MIDI and host changes smoothly; curves are cached; long parameter names fit the bar list; German EQ terms use the studio words.

New host parameters: `harmony.kb.inkey`, `harmony.kb.fixed` (appended). No new modulation sources or targets.

## Deutsch

**Vorabversion** – zum Testen und für Rückmeldungen. Es kann noch holpern; Presets und Parameter-IDs bleiben kompatibel (nur angehängt). Die Builds sind nicht signiert.

### Raster-Anordnungen und Akkord-Leitfaden
- Neue Anordnung **Sequenziell**: ein Feld nach rechts +1, eine Reihe hoch +8 – fortlaufende Reihen zu acht, wie beim Lesen einer Seite.
- Neuer Schalter **Nur Tonart / Chromatisch** für jede Anordnung (`harmony.kb.inkey`): Nur Tonart spielt nur die Töne der Tonart, die Reihen zählen Skalenstufen; Chromatisch spielt alle Töne, die anderen dunkel.
- Neuer Schalter **C fest** (`harmony.kb.fixed`). Aus, neu ab Werk: Das Feld unten links ist der Grundton der Tonart, eine Akkordform spielt also in jeder Tonart denselben Akkord. An: Es ist C.
- Die frühere Anordnung *In Tonart* öffnet jetzt als **Quarten + Nur Tonart**; Projekte und Presets damit öffnen so.
- Neue Regler-Seite **Harmonie > Raster** (Anordnung, Nur Tonart / Chromatisch, C fest). **Akkord-Leitfaden** mit Griffbildern in der Harmonie-Dokumentation und der Hilfe in der App.

### Grid-Controller
- **Scales halten** zeigt die Raster-Optionen im Display; die oberen Tasten wählen Anordnung, Nur Tonart, C fest, Grundton und Skala. Kurz drücken schaltet zur nächsten Anordnung. Display-Zeile 4 zeigt Anordnung / Nur Tonart / C fest / Oktave.
- **Bibliotheks-Modus** (Browse): die Preset-Bibliothek im Display des Controllers – Liste mit Nachbarn, Filter (Kategorie, Engine, Quelle, Favoriten, Tag, Bewertung, Sortierung) auf den Reglern, hoch / runter hört an, Select oder eine Part-Taste lädt, Shift = Favorit. Die Bibliothek am Bildschirm folgt.
- **Viele weitere Tasten** belegt und nach Zustand beleuchtet: Mute / Solo, Seiten Volume und Pan & Send für die vier Parts, Device (FX-Editor), Track (Mischer), Clip (Band), Accent, Quantize, Duplicate / Double, Delete + Schritt, New, Fixed Length, Automation, Add Effect, User (Zucht) und die Timing-Tasten 1/4 ... 1/32t als Notenwiederholung, solange gehalten.
- **Fußpedal**: Ein Haltepedal an der Pedalbuchse des Controllers hält jetzt Noten (Sustain CC 64, Sostenuto CC 66, CC 67 weitergereicht), auch in MPE-/Fingerboard-Parts. Vorher wurde es als Tastendruck genommen.
- Display-Zeile 3: Ein langer Presetname wird auf seine Spalte gekürzt, mit Leerzeichen vor dem Part.

### Arpeggiator und Pedale
- Das **Haltepedal** (von MIDI, Host, Grid-Controller oder einem MPE-Master-Kanal) hält jetzt die Noten des Arpeggios: losgelassene Tasten bleiben bis Pedal hoch im Muster, in der Zeit gedrückte kommen dazu. **Sostenuto** hält nur die beim Treten gedrückten Tasten. Pedal hoch ohne gehaltene Taste stoppt das Arpeggio sauber.
- Mit **Halten** ergänzen Tasten unter dem Pedal den gehaltenen Satz.

### FX-Editor
- Das Bild folgt Encoder-, MIDI- und Host-Änderungen flüssig; Kurven zwischengespeichert; lange Parameternamen passen in die Balkenliste; deutsche EQ-Begriffe wie im Studio.

Neue Host-Parameter: `harmony.kb.inkey`, `harmony.kb.fixed` (angehängt). Keine neuen Modulationsquellen oder -ziele.

## English

**Preview release** – for testing and feedback. Expect rough edges; presets and parameter IDs stay compatible (append-only). Builds are unsigned.

### Pressure glide
- New per-part **Glide Pressure** (−1 … +1, Pro view group *Glide*): aftertouch – channel or poly / MPE pressure – stretches the glide time (up to 4× slower) or shortens it down to instant. At 0 or without pressure, glide behaves exactly as before. Works with the glide knob and CC 5; CC 65 off still wins.

### SUB layer per part
- Every part gets a **sub oscillator** one or two octaves down (Sine / Round / Square), phase-locked to the voice pitch – bend, glide, pitch envelope and modulation included – band-limited and mono. Before or after the voice filter; on all eight synth engines.
- New encoder page and Pro view group *Sub*; **Sub Level** is a modulation-matrix target. Level 0 = existing sounds unchanged.

### Expressive playing
- Per-part **Expression page**: velocity and aftertouch each drive **two freely assignable functions** with amount and curve – filter, level, glide time, amp attack / decay / release and every other matrix target.
- New matrix source **Vibrato (5.5 Hz)**; new targets **Glide Time, Amp Attack, Amp Decay, Amp Release**.
- Gliding factory parts get an **aftertouch → glide time** preset (press harder = slower glide), unless they already use Glide Pressure.

### Mod wheel on every factory preset
- All **320 factory presets** now do something musical on the mod wheel: vibrato for leads, tremolo / auto-pan for keys, filter opening for pads and basses, grain spray for textures, vowel movement for choirs, echo throws for arps and more. Wheel down = the preset sounds exactly as before.

### 3D Space: more binaural motion paths
- Six new motion paths – **Ping-Pong front / back, Swarm, Whisper, Distance Walk, Over the Head, Weave** – and a path preview in the 3D view.

### Performance and CPU meter
- **CPU meter** on the mode column's legend line.
- Silent parts sleep (no tail is cut), a faster FM engine, hall and phaser on a cheaper sine, only changed parameters are synced per block, shared built-in tones.
- Measured with the new benchmark: **typical FM −42 %, silent racks −82 %, sum of all scenarios −14 %**.

### Settings, night mode, About and Help
- One **Settings** view (gear key in the header; the wordmark opens *About*): language, tooltips, help overlay (F1) and help pages; skin **Light / Dark (night) / Auto**, display brightness, animations, window size 75–150 %.
- **MIDI setup**: MIDI channel, MPE and bend range per part, MIDI inputs, clock and sync.
- **MIDI learn** overview: every mapping with control, channel, mode and range – edit, learn again, clear, import / export map files.
- **Night mode** covers the whole UI in warm dark greys with dimmed light bars; text contrast is checked.

### Content packs
- Install **`.ohpepack` content packs** from a file dialog or by **dragging the file onto the window**. Every file is checked against its **SHA-256**; a broken or incomplete pack is refused and the installed version stays.
- **Pack manager** in the library and in Settings: version, size, content, remove. The library filters by pack; presets that need a missing pack say so clearly instead of silently falling back.

### Wavetable banks
- Content packs can bring **wavetable banks**: read-only tables in the Wavetable engine's table menu (*Content packs*). Presets store only a reference to the pack's table.

### Fixes
- Help overlay tags are no longer cut off next to narrow controls.
- Night mode: octave labels on the white keys are readable.

## Deutsch

**Vorabversion** – zum Testen und für Rückmeldungen. Es kann noch holpern; Presets und Parameter-IDs bleiben kompatibel (nur angehängt). Die Builds sind nicht signiert.

### Glide-Druck
- Neuer **Glide-Druck** je Part (−1 … +1, Pro-Ansicht, Gruppe *Glide*): Aftertouch – Kanal- oder Poly-/MPE-Druck – dehnt die Glide-Zeit (bis 4× langsamer) oder verkürzt sie bis auf sofort. Bei 0 oder ohne Druck gleitet alles genau wie bisher. Wirkt mit dem Glide-Regler und CC 5; CC 65 aus hat weiter Vorrang.

### SUB-Ebene pro Part
- Jeder Part bekommt einen **Sub-Oszillator** eine oder zwei Oktaven tiefer (Sinus / Rund / Rechteck), phasenstarr zur Stimmtonhöhe – inklusive Pitchbend, Glide, Tonhöhen-Hüllkurve und Modulation –, bandbegrenzt und mono. Vor oder nach dem Stimmfilter; in allen acht Synth-Engines.
- Neue Encoder-Seite und Pro-Gruppe *Sub*; **Sub-Pegel** ist ein Ziel der Modulationsmatrix. Pegel 0 = bestehende Klänge unverändert.

### Ausdrucksstark spielen
- **Expression-Seite** je Part: Anschlag und Aftertouch steuern je **zwei frei zuweisbare Funktionen** mit Stärke und Kurve – Filter, Pegel, Glide-Zeit, Attack / Decay / Release und jedes andere Matrix-Ziel.
- Neue Matrix-Quelle **Vibrato (5,5 Hz)**; neue Ziele **Glide-Zeit, Amp-Attack, Amp-Decay, Amp-Release**.
- Gleitende Werks-Parts bekommen eine Voreinstellung **Aftertouch → Glide-Zeit** (fester drücken = langsamer gleiten), sofern sie nicht schon den Glide-Druck nutzen.

### Mod-Rad auf jedem Werks-Preset
- Alle **320 Werks-Presets** machen jetzt etwas Musikalisches mit dem Mod-Rad: Vibrato für Leads, Tremolo / Auto-Pan für Tasteninstrumente, Filteröffnung für Flächen und Bässe, Grain-Streuung für Texturen, Vokalbewegung für Chöre, Echo-Würfe für Arps und mehr. Rad unten = das Preset klingt genau wie vorher.

### 3D-Raum: mehr binaurale Bewegungspfade
- Sechs neue Bewegungspfade – **Ping-Pong vorne / hinten, Schwarm, Flüstern, Entfernungsgang, Über den Kopf, Wellenorbit** – und eine Pfad-Vorschau in der 3D-Ansicht.

### Leistung und CPU-Anzeige
- **CPU-Anzeige** auf der Beschriftungszeile der Modus-Spalte.
- Stille Parts schlafen (kein Ausklang wird abgeschnitten), schnellere FM-Engine, Hall und Phaser mit günstigerem Sinus, pro Block nur geänderte Parameter, gemeinsame eingebaute Klänge.
- Gemessen mit dem neuen Benchmark: **typisch FM −42 %, stille Racks −82 %, Summe aller Szenarien −14 %**.

### Einstellungen, Nachtmodus, Über und Hilfe
- Eine **Einstellungs**-Ansicht (Zahnrad-Taste im Kopf; der Schriftzug öffnet *Über*): Sprache, Tooltips, Hilfe-Overlay (F1) und Hilfeseiten; Erscheinung **Hell / Dunkel (Nachtmodus) / Auto**, Display-Helligkeit, Animationen, Fenstergröße 75–150 %.
- **MIDI-Einrichtung**: MIDI-Kanal, MPE und Bend-Bereich je Part, MIDI-Eingänge, Clock und Sync.
- **MIDI-Learn**-Übersicht: jede Zuordnung mit Regler, Kanal, Modus und Bereich – bearbeiten, neu lernen, löschen, Map-Dateien importieren / exportieren.
- Der **Nachtmodus** färbt die ganze Oberfläche in warmen Dunkelgrautönen mit gedimmten Leuchtbalken; der Textkontrast wird geprüft.

### Inhaltspakete
- **`.ohpepack`-Inhaltspakete** per Dateidialog oder durch **Ziehen der Datei auf das Fenster** installieren. Jede Datei wird gegen ihre **SHA-256** geprüft; ein beschädigtes oder unvollständiges Paket wird abgelehnt, die installierte Version bleibt.
- **Paketverwaltung** in der Bibliothek und in den Einstellungen: Version, Größe, Inhalt, Entfernen. Die Bibliothek filtert nach Paket; Presets, denen ein Paket fehlt, sagen das deutlich, statt still auszuweichen.

### Wavetable-Bänke
- Inhaltspakete können **Wavetable-Bänke** mitbringen: schreibgeschützte Tabellen im Tabellenmenü der Wavetable-Engine (*Inhaltspakete*). Presets speichern nur einen Verweis auf die Tabelle im Paket.

### Korrekturen
- Die Schilder des Hilfe-Overlays werden neben schmalen Bedienelementen nicht mehr abgeschnitten.
- Nachtmodus: Die Oktavbeschriftungen auf den weißen Tasten sind lesbar.
